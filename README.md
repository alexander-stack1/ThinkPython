# Pense em Python, 3ª edição

Notebooks Jupyter e demais materiais da 3ª edição de *Think Python: How to Think Like a Computer Scientist*, de Allen B. Downey, traduzidos para o **português brasileiro**.

Esta tradução é educacional, gratuita e sem fins lucrativos. O objetivo é ajudar quem, no Brasil, quer aprender lógica de programação em Python.

A autoria intelectual da obra é de Allen B. Downey (2024). A tradução (2026) não substitui a obra original nem altera essa autoria. O tradutor não está nominado; trata-se de tradução educacional para o português brasileiro.

## Como usar

Os capítulos estão em `chapters/`. As versões em branco, para resolver os exercícios, estão em `blank/`.

Comece por `chapters/jupyter_intro.ipynb` e siga para o Capítulo 1.

O código Python dos exemplos permanece em inglês, porque é a linguagem da própria Python. O texto didático, os enunciados e os glossários estão em português.
